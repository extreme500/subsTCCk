Passar nos próprios testes não bastou: só os testes do grupo mostraram as diferenças.

Usamos o GitHub Spec Kit como base, adaptado: uma constituição com seis princípios e um prompt por fase, idênticos nas duas ferramentas. O Clarify foi a fase mais útil e a única que exigiu esforço do grupo. As duas IAs aprovaram todos os próprios testes, mas os testes independentes, escritos a partir das decisões do grupo, mostraram diferenças. O Gemini declarou zero violações, o que a inspeção não confirmou.
