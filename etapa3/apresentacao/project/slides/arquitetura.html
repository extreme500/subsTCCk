ARQUITETURA E DESIGN

Monólito em camadas atrás de uma API REST

Camadas do diagrama de pacotes: controller → service → repository → model; nenhuma chama a de cima.

LUME, login e arquivos atrás de interfaces: os testes simulam o LUME fora do ar (CT02) e a queda no meio do download (CT06).

Decisões ligadas aos requisitos: download tudo ou nada (FA02); busca em campos normalizados, pelo início da palavra.

A arquitetura é pequena de propósito: escopo pequeno, equipe de três pessoas. O protótipo é o cliente dessa arquitetura, ainda sem servidor. As interfaces para os sistemas externos existem para que os casos de teste de falha possam ser executados. Microsserviços foram descartados por custo sem ganho neste escopo.
