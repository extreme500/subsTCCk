# Pacote de entrada do experimento de testes funcionais

Este pacote faz parte do trabalho prático de INF01127 (Engenharia de Software, UFRGS). Ele é usado para ampliar os casos de teste da Etapa 1 com os critérios de teste funcional (classes de equivalência e análise de valor limite), comparando ferramentas de IA. Cada ferramenta recebe exatamente este mesmo pacote e os mesmos prompts.

## Regras

- Use somente os arquivos desta pasta. Não procure material fora dela, nem na internet.
- Escreva em português.
- Não invente regras que o relatório não define: quando faltar uma regra, registre a lacuna.
- Pare ao fim de cada prompt; o próximo é enviado pelo usuário.

## Conteúdo

| Caminho | O que é |

| `contexto/relatorio-etapa1.md` | Problema, requisitos, user stories, casos de uso (UC01, UC04) e casos de teste CT01 a CT06 da Etapa 1 |
| `contexto/diagramas/*.png` | Diagramas UML da Etapa 1 |
| `contexto/diagramas/transcricao-diagramas.md` | Transcrição textual dos diagramas |
