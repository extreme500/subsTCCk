# Pacote de entrada do experimento de SDD

Este pacote faz parte do trabalho prático de INF01127 (Engenharia de Software, UFRGS). Ele é usado para aplicar Spec-Driven Development (SDD) a uma funcionalidade já especificada pelo grupo na Etapa 1, comparando ferramentas de IA. Cada ferramenta recebe exatamente este mesmo pacote e os mesmos prompts.

## Regras

- Use somente os arquivos desta pasta. Não procure material fora dela, nem na internet.
- Siga as fases na ordem e pare ao fim de cada uma; a próxima fase é pedida pelo usuário.
- Escreva os artefatos em português.
- Os artefatos de cada funcionalidade ficam em `specs/<número>-<nome>/` (spec.md, plan.md, tasks.md, analysis.md). O código fica em `src/` e os testes em `tests/`, na raiz desta pasta.

## Conteúdo

| Caminho | O que é |
|---|---|
| `.specify/memory/constitution.md` | Princípios que valem para todas as fases |
| `.specify/templates/` | Modelos de spec.md, plan.md e tasks.md |
| `contexto/relatorio-etapa1.md` | Problema, benchmark, requisitos, user stories, casos de uso e casos de teste da Etapa 1 |
| `contexto/diagramas/*.png` | Diagramas UML da Etapa 1 |
| `contexto/diagramas/transcricao-diagramas.md` | Transcrição textual fiel dos diagramas |
